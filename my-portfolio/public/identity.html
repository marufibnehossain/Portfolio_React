Netlify Identity

Use this page if invite / password links open your normal site and no login popup appears (React loads faster than the widget on the homepage).

Invite link fix: copy the link from your email, then change only the path so it starts with /identity.html and keep the whole #… at the end.
Example: https://marufibnehossain.com/identity.html#invite_token=…

Forgot password: click the button above, then in the popup use the Forgot password / Recover link (the widget does not support opening recovery directly). Or in Netlify go to Identity → Users → your user → Send reset password email and open the link using /identity.html#… like invites. Check spam for Netlify’s email.

Reset link does nothing?

Emails often point at your home page; the React app can break the flow. Use /identity.html and the recovery_token (or paste below).
